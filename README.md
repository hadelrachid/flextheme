# FlexTheme & Builder

> Extensao oficial para o ecossistema **[Domain-System OS](https://github.com/hadelrachid/domain-system)**.

Motor visual de renderização de vitrines, edição completa de temas e blocos de conteúdo para o Domain-System.

---

## 📌 Requisitos

- **Domain-System OS (CockPit)** versao 2.8 ou superior.
- PHP 8.2 ou superior com extensoes PDO, JSON e ZIP habilitadas.

---

## 🚀 Como Instalar no Domain-System (CockPit)

1. Baixe o pacote compactado `flextheme.zip` na secao de [Releases](https://github.com/hadelrachid/flextheme/releases/latest) deste repositorio.
2. Acesse o painel administrativo do seu site Domain-System (`/admin`).
3. No menu lateral, va ate a secao **Modulos (Plugins)**.
4. Clique no botao **Adicionar Novo** localizado no topo da pagina.
5. Selecione o arquivo `flextheme.zip` que voce acabou de baixar e clique em **Instalar Agora**.
6. O sistema validara a integridade do pacote, descompactara os arquivos em `src/Plugins/flextheme` e ativara o modulo imediatamente.

---

## ⚙️ Atualizacoes

Ao disponibilizarmos uma nova versao, o painel do Domain-System avisara automaticamente com um botao de atualizacao rapida em um clique, aplicando as melhorias com seguranca.
